## 一、施工内容

### L3b-1. 自己侧 API 直采（替代 capture-pane 看自己）

- relay 的"自己侧"从屏幕抓取改为**内部数据通道**：用户话题从 prompt.submit 直取，bobo 回复从 engine 输出事件直取；
- `find_own_pane()` 找不到时**不再中止**，自动走 API 直采模式；找到时两种模式均可（优先 API 直采， pane 模式保留为兼容路径）；
- **对方侧不变**：pi 必须仍在 tmux（它不会配合，只能 capture-pane + send-keys）；发送前复核（补丁③）原样保留；
- /scan 输出增加自我状态行：`当前 bobo：API 直采模式 ✓（无需 tmux）` 或 `pane 模式（<pane>）`。

### L3b-2. 全透明互传显示（样式定稿，owner 逐字确认版）

互传每一句**全文、实时**显示在用户 bobo 对话流，样式如下（零表情）：

```
─────────────────────────────────────────────
 互传中 · BOBO ↔ PI（<目标pane>）· 第 N/M 轮
─────────────────────────────────────────────

BOBO → PI   HH:MM:SS
  <全文，不裁剪>

PI → BOBO   HH:MM:SS
  <全文，不裁剪>

─────────────────────────────────────────────
 ESC 断开 · /disconnect 手动断开 · 日志留底
─────────────────────────────────────────────
```

样式规范：
- **BOBO 行 = 莫兰迪蓝 #7C93A8 加粗；PI 行 = 莫兰迪粉 #B69A94 加粗**（仅染"谁→谁 + 时间"行，正文不染）；
- 分隔线/状态行 = 莫兰迪灰 #9AA0A6；
- 色值可贴 TUI 现有主题微调，但必须是莫兰迪灰调双色、加粗、零表情；
- 同时写日志文件（全文留底备查）。

### L3b-3. 多模式隔离（bobo 提出，Kimi 采纳）

- relay 是一个**会话级活动状态**（类似 auto 的会话级开关，但语义是"进入一个房间"）：/connect 进入，/disconnect 或 ESC 退出；
- 互传显示、输入路由、relay 线程**只在多模式激活时存在**；退出后输入框/对话流/auto 决策/ESC 全部恢复原样，零残留；
- auto 与多模式正交：两个开关可任意组合，互不干扰；
- **强制回归断言：多模式关闭时行为零变化**（与"auto 关闭时行为零变化"同级纪律）。

### L3b-4. 测试

- API 直采模式：mock 输入/输出事件 → relay 正确收发（不经 tmux 自侧）；
- 显示层：双色加粗渲染用例、全文不裁剪断言；
- 回归：SCAN-L3 原测试全过（pane 模式兼容不破）。
