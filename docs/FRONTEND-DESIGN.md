## §2 借鉴研究（原则，不搬代码）

- **页面即节点**：每个黑箱节点一个页面/区域（参考成熟前端 19 页结构）；
- **schema 驱动长叶**：后端暴露配置 schema → 前端自动渲染表单——新增配置自动长叶，不用手写 UI（这是"节点长叶"的地基）。

## §3 前端方向（owner 2026-08-24 定，只聊不施工）

### 方向一：Skill → Capabilities（能力侧栏）
左侧边栏 skill 按钮改为 **capabilities**，含四个子区：

```
Capabilities
 ├─ Skills   可自定义（创建/编辑/删除——用户侧沉淀，接 D sediment_skill）
 ├─ Tools    展示（可路由工具/domain——未来可调）
 ├─ MCP      占位（结构先立，功能后做）
 └─ Learning ① 累积态（哪些模式在累积，计数→阈值路径）
             ② 沉淀知识（已落笔的 LESSON/技能，接 C 落笔 + D 沉淀）
```

- skills 自定义 = 用户侧沉淀（与 agent 自主沉淀两条路、同一落点）；
- MCP 占位：结构先有入口，显示"规划中"。

### 方向二：RL 显示（Learning 区）
- 形态：**B+C 方案**（owner 已定）——① 累积中的模式（计数→阈值路径）+ ② 已沉淀的知识（LESSON/技能）；
- 观察流（A）太吵，不做主视图（可作可展开调试视图）；
- 画像权重（D）独立考虑（灵魂直接体现，未定）。

### 方向三：spawn worker 增强（大板块）
- 用户可自定义：角色 · prompt · 模型 · 数量 · 超时；
- 接"模式=配置非循环"：worker 是主循环的可配置实例，非新循环；
- 天然 schema 驱动场景（后端暴露 worker 配置 schema → 前端自动渲染表单）。

## §4 共同地基与顺序

```
共同地基：schema 驱动长叶（后端暴露配置 schema → 前端自动渲染）
待定：① Skills 自定义表单字段（名字/描述/工作流——接 sediment_skill 入参）
       是否加"从当前对话沉淀"快捷入口；
     ② Learning 累积态是否"可调"（用户可停掉/标记不学某模式）还是先只"可见"。
```
