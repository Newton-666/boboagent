## 背景（2026-08-19 owner 反馈：长会话窗口反复崩溃消失）

**现象**：长会话（~200 条消息）后 renderer 内存触达 ~3.5GB → SIGKILL(137) →
窗口消失 → 自动重启 → 新会话又快速累积 → 循环崩溃。

**根因（Kimi 调查，events.jsonl 21:10-21:22 取证）**：
- chat 区 DOM **无限累积**：每条消息 appendChild（index.html:1646/1744），
  含 markdown 渲染后的完整子节点（代码高亮/表格/数学公式/SVG）；
- **无裁剪/无上限**：单会话 200+ 条消息全量驻留 DOM，从不释放；
- 证据链：21:17:44 客户端断开（eof=崩溃）→ 21:18/21:20/21:21 反复重启，
  每次新会话 3 分钟内又堆到 200 条 → 再崩。

**Owner 定调（关键约束）**：
- **目标**：滚动"丝滑不卡"（正常跟手、不跳变、无割裂）——**不追求极致
  120Hz**，不为高刷牺牲稳定性；
- **底线**：**所有功能细节必须保留、不能出错**（向上滚动能看到全部历史、
  增量更新、流式追加、代码块/公式渲染、引用高亮等一切现有行为零回归）；
- 宁可保守（虚拟滚动 + 适度 DOM 上限），不要激进优化引入新 bug。

## 施工项

### 1. 虚拟滚动容器（核心）

chat 区（#chat）改为**窗口化渲染**：
- 可视区 ± 上下缓冲（如各 500px）内只渲染需要显示的消息；
- 滚动时按**像素偏移**重算可视消息区间，**绝对定位 + transform 平移**
  （走 GPU 合成，滚动不触发全量重排）；
- 容器总高度用"消息数 × 行高估算 + 已渲染消息实际高度修正"维持滚动条
  正确比例（`overflow-anchor` 语义对齐）。

### 2. 消息高度管理

- 已渲染消息的实际高度缓存（Map: msgId → height）；
- 未渲染消息用**近似行高**（如 24px/行 × 行数估算）占位，渲染后修正；
- **代码块/表格/公式**等高度不稳定内容：渲染后更新缓存（宁可在滚动到
  附近时多做一次测高，不可让滚动条跳变失真）。

### 3. 全部现有行为保留（零回归清单，逐项验证）

- 流式追加（1646 行：append 后 scrollTop=scrollHeight 保持底部跟随）；
- 增量更新（append 模式 1644-1648：已有消息 .txt 追加内容）；
- 向上滚动查看全部历史（虚拟化不能丢消息——数据源仍是完整数组/后端）；
- 代码块高亮（hljs）、数学公式（KaTeX）、表格、diff 高亮、引用；
- user 消息动态块剥离（COST-5 stripDynBlock）；
- 工具调用卡片（1646 附近）、思考折叠（GUI-F8）、消息操作（复制/引用）；
- clearChat / 切会话 / 欢迎空态（1607/2646/2707 等）；
- 滚动位置保持（切回会话时 restore）。

### 4. 兜底上限（防极端）

- 即使虚拟化，DOM 节点仍设上限（如 ≤500 条实际渲染），超限强制回收
  最早的可回收节点（不可回收 = 屏幕外 + 无锚点引用的）；
- `pendingMessages`（main.cjs:25）窗口重建期缓冲加上限（≤200 条，
  超限丢最旧——窗口重建是短窗口期，丢几条事件可接受，防主进程 OOM）。

### 5. 性能验证（验收硬指标）

- **功能回归**：全量 pytest 零失败 + 桌面端既有 e2e 探针全过；
- **滚动帧率实测**：构造 200+ 条消息（含代码块/公式/表格混合），
  滚动实测帧率 ≥50fps（性能面板），且滚动全程无跳变/无白屏/无割裂；
- **内存实测**：长会话 200 条消息后 renderer 内存 <1.5GB（对比现状
  3.5GB 崩溃），且不再随消息数线性暴涨；
- **崩溃复现验证**：21:10-21:22 同款长会话场景（200 条 + 工具轮）连续
  跑 2 轮不崩溃。

## 风险自查点（Owner 底线：不出错 > 极致性能）

- **不追求 120Hz**：达标线 50fps 丝滑即可，禁止为帧率牺牲渲染正确性；
- **高度估算失真的兜底**：滚动条比例允许小幅修正，但**不能跳变/白屏**
  （宁可滚动到底时多做一次布局，不可闪）；
- **增量更新与虚拟化共存**：流式追加时若消息在可视区外，不得打断
  用户滚动（只在贴近底部时自动跟随，GUI-F27 活动超时语义保留）；
- **复杂内容**：代码块/公式渲染开销只影响"首次滚到该处"，滚动中的
  已渲染节点必须零重算；
- **不可回归项**：clearChat/切会话/欢迎空态/消息操作/引用/复制全保留；
- **TEL-8 守卫**：index.html 改动需特批登记 GUI-F29 标记；
- **write_obsidian 陷阱**：报告落 `library/agent开发/`（已错 7 次的教训）。
