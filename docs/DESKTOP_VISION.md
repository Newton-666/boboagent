# DESKTOP VISION — bobo 桌面端纲领

> v1.0 · 2026-08-13 · 立项背景：D-1 复活后 owner 实弹验收一周，对照 Hermes 桌面端解剖定纲

## 纲领第一条：体系自觉，学其手艺

**我们是自己的体系，不是 Hermes 的复制品。**

bobo 的骨架是世界上大多数 agent 没有的：票据工作流（领票→施工→五查→终审→回滚点）、EVAL 考场、记忆库、闸与纪律、多 agent office。桌面端的使命是**把这套体系画到界面上**——每一轮迭代回答一个问题："我们体系的哪一部分，现在在界面上还看不见/不好用？"

学习 Hermes（及任何优秀 agent）的方法论：**解剖其交互工艺，翻译为我们的内容**。学它的呈现手艺，装我们的工程组织。抄它的产品广度（messaging 平台、i18n、billing）是负债不是资产。

## 信息层级宪法（owner 2026-08-12/13 裁决汇编）

| 信息 | 处理 | 理由 |
|------|------|------|
| 动作（调了什么、改了哪文件） | **永不折叠**，一行可见 | 用户必须随时知道 agent 在干嘛 |
| diff（改了什么内容） | **与回复同级摊开**，整行底色（绿底+/红底−） | 批准/回滚的决策依据 |
| 思考过程 | 分段落摘要行 + 当前段蓝框，回合结束收起 | 思路脚印可见，但不淹没时间线 |
| 工具原始输出 | 折叠/预览 + 展开按钮 | 体积大，看结论即可 |
| 引擎诊断状态 | 不进消息区 | 内部噪音 |
| 回合时间线 | 永远只有"过去的一摞（聚合卡）+ 当下这一步（摊开）" | 3 步和 300 步同样清爽 |

及格线（owner 原话）：**TUI 能看清的，GUI 不许看不清。**

## 四根体系柱子（优先级排序）

1. **会话一等公民**（F3 已落地大半）：切换零丢失、历史全文（归档拼接）、选中态保真、状态跨端同步
2. **过程可读性**（F2/F3 已落地）：thinking 分段、diff 同级、聚合吞并
3. **任务持续性——我们的差异化**：票据面板（当前票+台账进度+五查状态+回滚点）、终审面板（对标 Hermes REVIEW 但更深：diff+五查报告+批准合并按钮+rollback 标签）、Automation 侧栏（对标其 CRON JOBS，我们已有体系）
4. **设置与环境完整性**：模型/密钥/日志/数据目录统一收口

## Hermes 解剖存档（2026-08-13 照片）

已识别的可学件：REVIEW 面板（→我们的终审面板，且我们更深层：五查+回滚）、CRON JOBS 侧栏（→Automation）、会话置顶+时间分组、Thought/Ran 分段摘要行（→F3-6 已对齐）、底栏模型选择器+分支显示（→我们加票据维度）。

明确不学：cron UI 之外的 platform 广度（webhooks/messaging/profiles/i18n/billing/多平台适配）。
